# AI 检索入门课

这是一个给 AI 新手用的课程素材库。

目标很简单：让不会复杂工具的人，也能用 AI 更快找到资料、判断资料、整理成能用的答案。

## 课程路线

1. 把问题说清楚
2. 让 AI 帮你拆关键词
3. 找到合适的资料
4. 检查资料是否可靠
5. 把资料整理成笔记、文章或方案
6. 用真实案例反复练习

- 刚开始用 AI 的人
- 想提高查资料效率的人
- 想把 AI 用到工作里的人
- 想系统学习一套简单方法的人

## 学习方法

每次只练一个小问题：先提问，再找资料，再核对，最后整理成能直接使用的结果。
